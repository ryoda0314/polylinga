# ことのあめ・ことしぐれ

作り直し中の言語学習アプリ（いまの名前は PolyLinga）の、新しい名前の候補と、その元になっている考え方のまとめです。

## どんなアプリか

同じかたちを使った短い例文が、音声付きで次々に流れてきます。学ぶ人はそれを浴びながら、どこが共通しているかに自分で気づき、気づいたかたちで自分でも言ってみます。それを AI が直し、直した文はそのまま友だちに送れます。

例文は日本語・英語・韓国語・中国語の4言語で同じ意味の文をそろえてあり、友だち同士で実際に送るようなチャット文です。いま4,000組以上あります。まずは日本語を話す人が、韓国語・英語・中国語を学ぶところから始めます。

## 設計の元になった考え

作者が韓国語を1年で「勉強する言葉」から「使う言葉」に変えた経験が出発点です。

> 一つの文章をそのまま覚えるのではなく、似た文章をいくつか集める。
> 가고 싶어요／먹고 싶어요／말하고 싶어요 … -고 싶어요は共通している。
> 「もしかして、この部分が『〜したい』を表しているんじゃないか」と考える。

> 知識として理解することと、自動的に使えることは別だった。その間を埋めていたのは、
> 反復。実際の使用。フィードバック。そして、忘れてもまた出会うことだった。

ここから、次のことを決めました。

- **文法は後から整理するもの。** 文法の一覧から入らない。かたちの説明は、浴びて自分で探したあとに、答え合わせとして見る。
- **量と反復。** 似た文をたくさん浴びると、共通している部分が自分で見えてくる。
- **音が主役。** 文字を見ながら音を聞く。すべての例文に音声を付ける。
- **メモは自分の指で打つ。** ボタンひとつで保存しない。打つ手間に意味がある。見返さなくていいし、忘れていい。
- **また出会うのはシャワーの中。** テストや復習は強制しない。浴びたかたちは、日をあけて別の文の中でまた流れてくる。
- **使いながら使えるようになる。** 浴びたかたちで自分の文を作り、直してもらって、そのまま使う。
- **AI は添削だけ。** 例文は先に作り溜めておき、学ぶ人が使うときに AI を呼ぶのは添削だけにする。

流れにすると、この4つだけです。

**浴びる → 気づく → 言ってみる → また出会う**

この流れに入らない機能は作りません。前の版は、生成 AI に頼りすぎ、機能と対象言語を広げすぎて、操作が難しくなり、最初の考えから離れていきました。今回はその反省からの作り直しです。見た目も、白い紙に墨の文字、アクセントは1色だけと静かにしています。

## 名前の候補

どちらも「言葉が雨のように降ってくる」様子を表す名前で、例文のシャワーを日本語の言葉に置き換えたものです。

### ことのあめ（言の雨 / Kotonoame）

古今和歌集の仮名序にある「言の葉（ことのは）」の「葉」を「雨」に変えた言葉です。言葉を葉のように茂らせるのではなく、雨のように降らせて浴びる。やわらかく、誰でも一度で読めます。

### ことしぐれ（言時雨 / Kotoshigure）

時雨（しぐれ）は、降ってはやみ、またやってくる雨です。浴びたかたちが日をあけて新しい文で戻ってくる、このアプリの「また出会う」と重なります。蝉時雨（せみしぐれ）や木の葉時雨と同じ「◯◯が雨のように降る」作りです。耳で聞くと「今年（ことし）・ぐれ」と区切れて聞こえやすいので、ロゴでは漢字の「言時雨」を見せると伝わります。

| | ことのあめ | ことしぐれ |
|---|---|---|
| 伝わりやすさ | 一度で読めて、意味も分かる | 漢字を見ると意味が分かる |
| コンセプトとのつながり | 例文の雨を浴びる | 降ってはやみ、また降る（また出会う） |
| 気になる点 | 「また」の意味は名前に入らない | 耳では「今年暮れ」と聞こえやすい |

## アイコン案

「雨」の下に「言」と書く「霅」という漢字があります。説文解字では、雷雨のさまのほかに「大勢の話し声」という意味もあるとされる字で、成り立ちからして「言葉の雨」です。この字を細い線で描き、四つの雨粒だけをアクセントの青にする案を第一候補にしています。どちらの名前とも合います。
