# ことのあめ — 紹介映像

アプリの映像。1920×1080・30fps・約111秒、字幕とナレーション（Gemini TTS）。Remotion 4 で作る（アプリとは別のプロジェクト）。
作り方は姉妹アプリ ことのは・ことのめ・ことのえだ・ことのね の映像（`../../english/promo`・`../../hangul/promo` など）に
そろえた：アプリの画面を、アプリの CSS と文言のとおりに描き直し、その横に一文ずつ言葉を置く。録画ではない。

見る人：文法は分かるのに、使えない人。似た文を浴びて、共通しているところに自分で気づき、そのかたちで言ってみて直して
もらい、忘れてもまた出会う（`../CONCEPT.md`）。流れは使い方（`/tutorial`、`../src/app/tutorial/Tutorial.tsx` の冒頭に
「the promotion film's beats」とある）と同じ順：浴びる → 気づく → 言ってみる → また出会う → 続ける。

| | 画面 | 映像の言葉 |
|---|---|---|
| 問い | 雨の筋。ライブラリの3文（내일 카페 갈래? など）が降り、文と訳の同じところ（갈래 と ない）が光る | 「分かる」と「できる」のあいだを埋める。/ 似た文を、いくつも浴びて、共通しているところに、自分で気づく。 |
| 名前 | アイコンと ことのあめ | 言の葉は、言の雨に育まれる。 |
| 浴びる | 雨の最初の画面（はじめてのかたち・雨が来ています・浴びる）。誘うの4文が、置き場の声で一つずつ降る | 同じかたちの文が、音声付きで降ってくる。 |
| 気づく | 「共通しているところは？」→ 文と訳の同じところに色。共通していたところ：誘う | 共通しているところに、自分で気づく。 |
| メモ | 주말에 영화 볼래? を押して、気になった語のシート。「주말」を自分で打って、メモしました | 知らない語は、自分の指で打ってメモ。 |
| 言ってみる | これで言ってみる：さっき降ってきた文の下の欄に、使い方の例の文（주말에 영화 보러 가을래?）。直してもらう | 浴びたかたちで、自分のことを言ってみる。 |
| | 浴びたかたちで言ってみた：あなたの文（가을 に線）、直した文（갈、メモした 주말 は紫の点線）、コピーしました、詳しく解説で 갈래 と「行かない？」が光る、どこを直したか | AI が直して、理由を説明してくれる。 |
| また出会う | 今日 → 3日後（使い方の日の帯）。前にも降ったかたち・3日ぶり、メモした「주말」も降ってきます。まだ出会っていない4文が降り、주말 が紫の点線 | 忘れたころに、また降ってくる。 |
| 3つの言葉 | はじめの画面（どの言葉の雨を浴びますか？）で 韓国語・英語・中国語（ピンイン付き）。同じ文（今日カラオケ行かない？）が、それぞれの雨で、それぞれの声で | 韓国語・英語・中国語を、日本語から。 |
| 続ける | 使い方の最後の画面：電車の窓、いつ浴びることにする？、電車に乗ったら、決めました | 毎日のあとに、ひと雨。 |
| 終わり | 名前、今日の雨を、少し浴びてみる。タブ、無料ではじめる | 浴びる・音声・メモは無料。AI 添削は1日20回まで無料。 |

## 中身はどこから

- 例文・訳・光るところ：アプリのライブラリ（`pl_sentences`・`pl_sentence_patterns`・`pl_functions`）を、公開の鍵（anon）で
  読むだけ。公開済みの文は誰でも読める。書き込まない、ログインしない。誘う（`ko-eullae`）の文から：最初の雨は使い方の
  4文、3日後の雨は使い方の2文とライブラリの2文（오늘 밤 라멘 먹을래?・이따가 같이 산책할래?）。本物の雨も4文
  （`../src/lib/shower.ts` の CLUSTER_SIZE）で、また降るときは、まだ出会っていない文から。
- 例文の声：アプリの公開の置き場（`pl-audio`、名前は文の sha256）からそのまま。大きさだけナレーションにそろえる。
- 言ってみるの例：使い方の韓国語の例（`../src/lib/tutorial.ts` の PICKS.ko）そのまま。AI は呼んでいない（使い方と同じ）。
  直したところはアプリの diff（`../src/lib/diff.ts`）で出す。直した文 주말에 영화 보러 갈래? の声は置き場に無いので、
  再生ボタンは描くが鳴らさない。
- 料金の一行は、はじめの頁の料金（`../src/app/page.tsx`。AI 添削の回数は公開中の頁で 20 回と確かめた）。

## 音

- ナレーション：台本は `voice/lines.json`（画面の字幕とは別の、耳で聞く文。言の葉 → ことのは、1分 → 一分）。
  Gemini TTS（`gemini-3.1-flash-tts-preview`、声 Kore）を Vertex AI で。鍵は ことのあめ の `../.env.local`
  （`GOOGLE_SERVICE_ACCOUNT_KEY`・`GOOGLE_CLOUD_PROJECT`・`GOOGLE_CLOUD_LOCATION`）。鍵はこのリポジトリに置かない。
  `--check` で書き起こして台本と並べた（V08・V09 は「語」が「午後」などに聞こえたので「言葉」に、V07 は作り直した）。
- 映像の時は、声の長さから決まる（`src/voice.json`・`src/clips.json`。`src/timeline.ts` は声が言い終わってから次へ）。
  ナレーションの中の言葉に合わせるところ（「答え合わせは」で押す、など）は、クリップの息つぎの位置で決めてある。
  ナレーションは例文の声に重ねない。声のあいだは音楽が下がる（`src/Promo.tsx` の DUCKING）。
  声を作り直したら `music` も走らせ直す。
- 音楽と小さな音は `scripts/music.py`（姉妹と同じ作り方）。だれかの曲は使っていない。
- 機械で確かめたこと：WAV の形・レート・山・頭の無音・声の大きさ（例文の声は -1 dBFS を越えない）。
  耳で聞いての確かめ（声の感じ・速さ・つり合い）は、機械ではできない。

## 作り方

```bash
cd promo
npm install
npm run assets     # アイコンと芽の絵、ライブラリの例文と置き場の声、字（映像に出てくる字だけに切る。Python の fontTools）
npm run voice -- --env ../.env.local    # ナレーション（まだ無いものだけ。--force・--only V01・--check）
npm run music      # 音楽と小さな音（Python と numpy。映像の区切りに合わせて作る）
npm run studio     # 見ながら直す
npm run render     # out/kotonoame-promo.mp4
npm run stills -- 300 1240     # 1コマだけ out/stills に
```

- 画面はアプリの CSS と文言から描き直している（`src/ui.tsx`、`src/scenes/`）。電話の幅はアプリの枠のいちばん広い
  560px。アプリの見た目や言葉を変えたら、ここも変える。
- 字（IBM Plex Sans JP・IBM Plex Sans KR・Noto Sans SC・しっぽり明朝）は映像に出てくる字だけに切ってある。言葉を変えたら
  `assets` を走らせ直す。
- 色は `remotion.config.ts` で bt709・yuv420p（姉妹と同じ。JPEG のコマのままだと薄い灰色が白く飛ぶ）。
- アプリの `tsconfig.json` と `eslint.config.mjs` からは外してある（姉妹と同じ）。`node_modules/`・`out/` と、
  `assets`・`music` で作り直せるもの（`public/app`・`public/fonts`・`public/sound`）は `.gitignore` に。
- 見せる中身は `../CONCEPT.md` のとおり：点数・正答率・連続記録は出さない。
