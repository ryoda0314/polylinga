# ことのあめ — 紹介映像

アプリの映像。1920×1080・30fps・約140秒、字幕とナレーション（Gemini TTS）。Remotion 4 で作る（アプリとは別のプロジェクト）。
作り方は姉妹アプリ ことのは・ことのめ・ことのえだ・ことのね の映像（`../../english/promo`・`../../hangul/promo` など）に
そろえた：アプリの画面を、アプリの CSS と文言のとおりに描き直し、その横に一文ずつ言葉を置く。録画ではない。

見る人：文法は分かるのに、使えない人と、はじめたばかりの人。似た文を浴びて、共通しているところに自分で気づき、そのかたち
で言ってみて直してもらい、忘れてもまた出会う（`../CONCEPT.md`）。流れは使い方（`/tutorial`、`../src/app/tutorial/Tutorial.tsx`
の冒頭に「the promotion film's beats」とある）と同じ順：浴びる → 気づく → 言ってみる → また出会う → 続ける。

言ってみて直してもらうところを見せたあと、出てきそうな突っ込み「はじめたばかりで語彙が無いのに、言ってみるなんて無理では？」
に答える：材料は、いま浴びた4つの文（さっき言ってみた文の言葉は、もう文と訳の中にある）。どれがどの意味かは分からないが、文を
押して語を選べば、その語を使ったほかの文がいくつも出てくるので、見比べて予測できる。確かめなくていい。そのまま使って、違って
いたら直してもらえばいい（さっきの添削に戻る）。

| | 画面 | 映像の言葉 |
|---|---|---|

## 中身はどこから

- 例文・訳・光るところ：アプリのライブラリ（`pl_sentences`・`pl_sentence_patterns`・`pl_functions`・`pl_patterns`）を、
  公開の鍵（anon）で読むだけ。公開済みの文は誰でも読める。書き込まない、ログインしない。〜したい（`ko-go-sipeo`）の文から：
  最初の雨は使い方（`../src/lib/tutorial.ts` の PICKS.ko）の4文、3日後の雨は使い方の2文とライブラリの2文
  （주말에 만나고 싶어.・카페에서 공부하고 싶어.）を、アプリと同じく短い文から。本物の雨も4文（`../src/lib/shower.ts` の
  CLUSTER_SIZE）で、また降るときは、まだ出会っていない文から。光るところは、その働きの、その言葉のかたちの印だけ。
- 語のシートの「ほかの文」：アプリの `sentencesWith`（`../src/lib/shower.ts`）と同じ問い合わせ（その語を含む公開済みの文、
  押した文を除いて5つまで）。語の並びはアプリと同じく Intl.Segmenter。오늘은 は5つ出てきて、訳がどれも「今日は」なので選んだ
  （한국에・딸기 はほかの文が一つしかなく、見比べられない）。
- 例文の声：アプリの公開の置き場（`pl-audio`、名前は文の sha256）からそのまま。大きさだけナレーションにそろえる。
- 言ってみるの例：三文目で予測した 오늘은、一文目の 한국에、二文目で組んだ 오늘은 한국에 딸기 먹고 싶어.（`scripts/assets.mjs`
  が、雨の文だけで組めていることを確かめる）。直した文・訳・どこを直したかは、アプリの添削（`../src/lib/ai.ts` の
  correctSentence を、これで言ってみると同じく intent なし・練習中のかたち V + 고 싶어 で）がこの文に返したもの、詳しく解説の
  語は explainSentence が返したもの（2026-11-01、gpt-5.2。3回とも 한국 딸기 に直した）。映像を作るときは AI を呼ばない
  （使い方と同じ）。ほかに試してやめた例：
  - 한국에 딸기 먹고 싶어.（韓国で）：한국에서 と直すが、한국에 のほかの文は一つしかない。
  - 일찍（早く）を予測して 빨리 と直される例：添削は 일찍 のまま通した（早めに、と読む）。
  - 오늘은 딸기 먹고 싶어 아이스커피 마시고 싶어.：直し方が回ごとに違い、説明が韓国語で返ってきた（アプリの添削でも起こりうる）。

  直したところはアプリの diff（`../src/lib/diff.ts`）で出す。直した文の声は置き場に無いので、再生ボタンは描くが鳴らさない。
- 料金の一行は、はじめの頁の料金（`../src/app/page.tsx`。AI 添削の回数は公開中の頁で 20 回と確かめた）。

## 音

- ナレーション：台本は `voice/lines.json`（画面の字幕とは別の、耳で聞く文。言の葉 → ことのは、1分 → 一分）。
  Gemini TTS（`gemini-3.1-flash-tts-preview`、声 Kore）を Vertex AI で。鍵は ことのあめ の `../.env.local`
  （`GOOGLE_SERVICE_ACCOUNT_KEY`・`GOOGLE_CLOUD_PROJECT`・`GOOGLE_CLOUD_LOCATION`）。鍵はこのリポジトリに置かない。
  `--check` で書き起こして台本と並べた（前の版の V08・V09 は「語」が「午後」などに聞こえたので「言葉」に。V17・V18 も「語を
  選ぶ」が「5を選ぶ」と聞こえたので「単語」に、V23 は「言ってみて」が「行ってみて」と紛れるので「使ってみて」に。V14 は
  「浴びた」が「挙げた」と、V06 は「ありた」と聞こえたので作り直した）。
- 映像の時は、声の長さから決まる（`src/voice.json`・`src/clips.json`。`src/timeline.ts` は声が言い終わってから次へ）。
  ナレーションの中の言葉に合わせるところ（「答え合わせは」で押す、など）は、クリップの息つぎの位置で決めてある。
  ナレーションは例文の声に重ねない。声のあいだは音楽が下がる（`src/Promo.tsx` の DUCKING）。
  声を作り直したら `music` も走らせ直す。
- 音楽と小さな音は `scripts/music.py`（姉妹と同じ作り方）。だれかの曲は使っていない。
- 機械で確かめたこと：WAV の形・レート・山・頭の無音・声の大きさ（例文の声は -1 dBFS を越えない）。
  耳で聞いての確かめ（声の感じ・速さ・つり合い）は、機械ではできない。

## 作り方

```bash
cd promo
npm install
npm run assets     # アイコンと芽の絵、ライブラリの例文と置き場の声、字（映像に出てくる字だけに切る。Python の fontTools）
npm run voice -- --env ../.env.local    # ナレーション（まだ無いものだけ。--force・--only V01・--check）
npm run music      # 音楽と小さな音（Python と numpy。映像の区切りに合わせて作る）
npm run studio     # 見ながら直す
npm run render     # out/kotonoame-promo.mp4
npm run stills -- 300 1240     # 1コマだけ out/stills に
```

- 画面はアプリの CSS と文言から描き直している（`src/ui.tsx`、`src/scenes/`）。電話の幅はアプリの枠のいちばん広い
  560px。アプリの見た目や言葉を変えたら、ここも変える。
- 字（IBM Plex Sans JP・IBM Plex Sans KR・Noto Sans SC・しっぽり明朝）は映像に出てくる字だけに切ってある。言葉を変えたら
  `assets` を走らせ直す。
- 色は `remotion.config.ts` で bt709・yuv420p（姉妹と同じ。JPEG のコマのままだと薄い灰色が白く飛ぶ）。
- アプリの `tsconfig.json` と `eslint.config.mjs` からは外してある（姉妹と同じ）。`node_modules/`・`out/` と、
  `assets`・`music` で作り直せるもの（`public/app`・`public/fonts`・`public/sound`）は `.gitignore` に。
- 見せる中身は `../CONCEPT.md` のとおり：点数・正答率・連続記録は出さない。
